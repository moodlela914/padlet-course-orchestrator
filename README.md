# Padlet 運課設計師

把課程主題或教材轉成依序進行的 Padlet 課程設計：從先備觀念、問題情境、示範到實作、評量與回饋。

## 功能

- 規劃各區段的教學目的、引導語、學員任務與代表性圖片。
- 設計 Padlet Arcade 形成性和總結性評量，以及最後的收斂問答。
- 依實際學員貼文產生個別回饋，並在工具和授權允許時建立留言。
- 使用可用的 Padlet 工具建立課程牆與活動；可用功能視連線及權限而定。持續自動回覆需另有支援新貼文觸發的工具。

## 安裝與使用

將本儲存庫複製到 Codex 的 skills 目錄（例如 `~/.codex/skills/padlet-course-orchestrator`），或使用支援 Agent Skills 的環境讀取 `SKILL.md`。重新開啟或重新整理技能清單後，輸入：

> 使用 $padlet-course-orchestrator，根據我上傳的教材，設計一場給國中教師的兩小時研習，並建立 Padlet 課程牆。

需要實際建立 Padlet 與 Arcade 時，須連接 Padlet 工具並具備相應權限。只要求課程規劃時，Skill 會先提供可貼上的內容。
